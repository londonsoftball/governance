# London Softball League Governance Documents

The home of the LSL constitution and standing orders.

## Description

Historically, the original versions of the LSL Constitution and Standing Orders have been kept in a Microsoft Word document owned by the committee.
These are published regularly each season as a PDF after being updated based on proposals and discussion at the Annual General Meeting.

Microsoft Word is a proprietary format that not everyone can access - we've decided to move these to markdown to ensure they are open to all.
Using github also gives us greater transparency on changes, with an clear audit record and (if needed), independent approval of any changes.

## Involvement

We welcome contributions from the league. If you have a straightforward change (fixing a typo, cleaning up some confusing language), please
open a PR. Changes will generally be included in the following season's updates.

**Note** we reserve the right to reject any change in favor of a vote at the AGM.
